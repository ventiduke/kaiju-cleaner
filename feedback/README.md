# Playtest feedback

Drop session files saved from the game here ("save full session file" in the panel), or paste the text from
"copy settings + notes" into a chat. Either gives an agent the settings you changed, your notes, and what happened
in the run.

To read one:

```sh
npm run feel -- feedback/kaiju-session-2026-11-14-22-30.json
```

That prints your notes and run stats, how your settings handle in a fixed set of scripted maneuvers next to the
defaults, and a replay of your inputs on the current build.
